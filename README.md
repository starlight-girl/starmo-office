## 当前功能

- Word、Excel、PowerPoint 文档查看与编辑，保存到用户选择的位置。
- PDF 只读预览；不提供 PDF 正文编辑。
- 文件列表、类型筛选、最近文档、中英文界面与界面字号设置。
- 在线模板按需下载。

**Office 编辑依赖网络和独立的 Collabora/WOPI 服务，并非纯离线应用。** 界面语言切换不翻译用户的文件名或文档正文。
